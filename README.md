# Kotoba — official App Store website

Static, English-language public pages for **Kotoba: Japanese From Zero**.

## Published pages (once GitHub Pages is enabled)

- Home: https://ukrbanditos-svg.github.io/kotoba/
- Privacy Policy: https://ukrbanditos-svg.github.io/kotoba/privacy.html
- Support: https://ukrbanditos-svg.github.io/kotoba/support.html

**These links are not live until GitHub Pages finishes deploying.** The repository was private when this site was uploaded. On a free GitHub plan, make the repository public first, then visit **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

The support page currently uses [GitHub Issues](https://github.com/ukrbanditos-svg/kotoba/issues/new) because the developer has not supplied an email address to publish. Keep Issues enabled on the public repository, or add a real support email to `support.html` before submitting the app.

The privacy policy is based on the current native offline-first SwiftUI app and must be reviewed against the exact build being submitted, particularly if analytics, third-party SDKs, accounts, microphones, or network features are added.

Content and styles are all static HTML/CSS with no tracking scripts.
